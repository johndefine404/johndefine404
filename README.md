## 맡는 일

- 운영 중인 웹사이트 수정과 유지보수
- 홈페이지·랜딩페이지 기획부터 배포까지
- AI로 만든 웹·앱의 검수, 보안 점검, 배포, 스토어 등록
- UX/UI와 서비스 기획
- 위 오픈소스의 설치와 맞춤 설정
